# Assignment 4 вЂ” Jetpack Compose



## Overview



This repository contains Android applications developed for Assignment 4: State and User Interaction in Jetpack Compose.



The applications are written in Kotlin using Jetpack Compose.



## 1. Tip Time Application



The Tip Time application calculates tips based on the bill amount and a custom tip percentage.



**Features:**

- Bill amount input

- Custom tip percentage

- Automatic tip calculation

- Round-up tip switch

- Numeric keyboard support

- Responsive layout

- Leading icons in input fields



**Testing:**

- JUnit local unit tests

- Jetpack Compose UI tests

- Tip calculation and rounding verification



## 2. Art Space Application



Art Space is an interactive art gallery application.



**Features:**

- Display artwork images

- Show artwork titles, artists, and years

- Previous and Next navigation buttons

- State management using Jetpack Compose

- Support for phone and tablet layouts



**Artworks:**

- The Starry Night вЂ” Vincent van Gogh

- The Great Wave off Kanagawa вЂ” Katsushika Hokusai

- Girl with a Pearl Earring вЂ” Johannes Vermeer

## 4. How to Run



1. Open Android Studio.

2. Open either the `TipTime` or `ArtSpace` directory as an Android project.

3. Wait for Gradle Sync.

4. Select an emulator or Android device.

5. Click Run.
